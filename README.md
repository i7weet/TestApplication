## Тест

Тест создаёт и завершает задачу через API, затем проверяет вызов
ITaskEventPublisher и содержимое события.

## Принятые упрощения

- HACK: Нет outbox и повторной доставки. При ошибке RabbitMQ задача
  остаётся завершённой, событие и ошибка записываются в лог.
- HACK: Publisher confirms отключены, получение сообщения брокером
  не подтверждается.
- HACK: В тесте используется заглушка издателя и PostgreSQL из Compose.
  Следующим шагом добавил бы изолированную тестовую БД и проверку
  фактической доставки в RabbitMQ.
